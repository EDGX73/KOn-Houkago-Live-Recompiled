# Windows y Android — instalación y compatibilidad 0.2.0

Documento preparado para la próxima publicación; los enlaces de la 0.2.0 solo funcionarán cuando se publique.

Windows: descarga el ZIP Windows, descomprímelo, abre el ejecutable y selecciona tu propia ISO. Conserva las instrucciones y requisitos Windows del README. Sus opciones de vídeo, controles de teclado y funciones de PC no describen Android.

Android: descarga la APK arm64 de la release v0.2.0, instálala, selecciona tu propia ISO mediante el selector de archivos de Android (SAF), pulsa «Preparar juego» y después «Jugar». La preparación se realiza en el dispositivo, sin PC ni importación de `game.kon`. El equipo técnico estima 20–40 minutos y aproximadamente 1 GB libre: no son medidas verificadas por el publicador en el S24. La descarga no debe contener ISO ni módulos generados del juego. El tamaño y hash definitivos se añadirán al cerrar la build vc201.

La única prueba física comunicada para la candidata anterior es un Samsung Galaxy S24: funciona, con rendimiento mejorable. Android todavía carece de opciones/mejoras disponibles en PC. No se afirma compatibilidad con otros teléfonos, x86_64, iOS, Linux o macOS; ni paridad funcional, rendimiento medido, audio verificado o jugabilidad completa. La build corregida necesita un nuevo test.

Fuentes de esta descripción: contexto técnico facilitado por Recomp K-On y prueba del usuario transmitida por Mugi. La auditoría del publicador es estática.
