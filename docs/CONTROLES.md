# Controles del prototipo para PC

Abrir `Probar ingles.cmd` o `Probar japones.cmd` desde la raíz del proyecto.
La ventana debe tener el foco. **F1 muestra u oculta esta guía dentro del juego**;
no pausa la ejecución.

| Control PSP | Tecla |
| --- | --- |
| Cruceta arriba / abajo / izquierda / derecha | Flechas |
| Triángulo △ | S |
| Círculo ○ | X |
| Cruz × | Z |
| Cuadrado □ | A |
| L | Q |
| R | W |
| START | Enter |
| SELECT | Retroceso (Backspace) |
| Stick arriba / izquierda / abajo / derecha | I / J / K / L |

Se pueden mantener varias teclas a la vez. El stick admite diagonales; las
direcciones opuestas se cancelan. El stick de teclado alcanza el extremo de
cada eje, mientras que un mando puede dar posiciones intermedias.

Las etiquetas de los diálogos siguen mostrando botones PSP: **○ corresponde a
X del teclado** y **× corresponde a Z**. En las pantallas comprobadas, círculo
confirma y cruz vuelve. START y SELECT conservan su significado original:
no todas las pantallas del juego responden a ellos.

El mapeo cubre todos los controles de juego de PSP. HOME, brillo, volumen,
interruptor WLAN y encendido son controles del sistema de la consola y no
acciones enviadas al juego. El cierre y el volumen se gestionan desde Windows.
La reasignación desde Ajustes sigue pendiente.

Este ejecutable sigue siendo un prototipo: puede detenerse al encontrar una
función pendiente y conservar la última imagen. Aún no se ha verificado una
canción completa; no debe confundirse una parada del port con un fallo de tecla.
